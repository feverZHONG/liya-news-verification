## 模板细节

### 1. 积分兑换诈骗（同一伙人换马甲撒网）

话术：「尾号1772用户您合计688800分/26年累计XX分即将失效/清空，可换华为手机/珠宝/家电」

- 用「今日到期/即将失效」制造紧迫感
- 落地页特征：`/pages/invest/index?type=1&code=XXX`（投资诈骗页）
- 实测短链域：buf8.cn / m0u5.cn / x8l.cn / buo0.cn（4 个不同域名，同一模板）
- 识别：尾号 + 积分失效 + 可换手机家电 = 直接当诈骗

### 2. 医保/社保诈骗（官方已发预警）

话术：「肇庆1772城乡居民医疗报销金已打款，请尽快点XXX查看」

- 多地反诈中心 2026-05 已发预警「谨防虚假居民医保补助金短信链接诈骗」
- 实测：1rk.cn（随机短域名直连）
- 识别：报销金/补助金已打款 + 不明链接 = 诈骗

### 3. 保险/保障诈骗（同伙第 2 套话术）

话术：「您的健康保护已入账!不验证作废」/「保障险尚未激活，逾期作废」

- 与医保诈骗同源，用「作废」制造恐惧
- 实测短链域：tf1.cn / kq1.cn / k7z.cn（3 个马甲，同一伙人）
- 品牌伪装：众安经纪 / 泰康保单 / 众安优保 / 相安保
- 识别：XX已入账/未激活 + 逾期/不验证作废 + 随机短链 + 尾号 = 诈骗

### 4. ETC/通行诈骗

话术：「您的通行IC处于禁用状态，请于X月X日前点开XXX解除禁用」

- 经典 ETC 诈骗话术（公安反诈预警类型）
- 实测：a.baox46.cn（随机短域名直连）
- 识别：通行/ETC禁用 + 解除链接 = 诈骗

### 5. 荐彩/六合彩诈骗（无链接，微信号引流）

话术：「上回X（生肖暗语）又准了」「今晚必出3个码」「免费赠送6合好料包种三玛」

- **无 URL，全是「加微信/加薇」**——linkcheck 管不到，靠话术识别
- 生肖/数字暗语：潴=猪、汼=牛、鎷/傌=码、淇=期、佪=回、宜莦=生肖、6何采=六合彩、矀/徾/葳/伽徽=微信
- 用错别字/谐音规避关键词过滤
- 先免费荐号建立信任 → 后诱导付费/下载APP/充值
- 公安长期打击（2003 安溪报道、2022 广西团伙案例）
- 赌博站域名特征：纯数字/随机短域名（45008.cn 类，打一枪换域名，很快失效）
- 识别：无链接 + 生肖暗语 + 加微信 + 「必中/稳了」= 直接忽略

### 6. 官方营销（对比参照）

- 品牌短链跳官方主域 = 绿
- 已验明官方短链：见 `verified-shorteners.md`
- 注意「100%有礼」「现金红包」是营销钩子，不是诈骗，但别指望大奖

### 7. 假通知/账单催缴体（无链接 · 纯话术型）

话术：「尊敬的客户：您于X日购买的『穿越回国庆前』套餐已生效，由于本公司的服务发生偏差导致您多回了N天，对于这多余的天数本公司需要向您收取额外的手续费总共5万眼——但根据人道主义考虑您仅需向我支付50元即可免除本次债务」

- **无链接、无尾号**，靠公文腔立信，linkcheck 管不到这类。现实版本的内核就一句——**「多出来的权益要付费解除」**（会员/期权/积分/贷款额度「已开通，不取消将扣费」全是它的马甲）
- **识别五要素**（凑三样以上先按钓鱼处理，不必逐字读完）：
  ① 权威通知体（「尊敬的客户/用户您好」——先把你放进「客户」位）
  ② 精确到分钟的时间戳（「截至X日X时X分」——越像后台数据越可信）
  ③ 硬期限（「今日24时前」——不给查证时间）
  ④ 小额落点（50 元级——让「算了先交了」比核实更省事）
  ⑤ 群体裹挟（「本群的N个…」「别耽误大家」——把损失换成「别连累别人」）
- **段子与诈骗同骨架**：2026-09-17 用户两发的都是这副骨架的**段子版**（笑点在落点 50 元）。同一骨架换成真短信/真弹窗就是要钱，**分界只有一条——钱会不会真的出去**（有无收款码/链接/真账单渠道）。当段子笑可以，但把「落点＝50 元」记成锚点，别让同骨架的真版本从眼皮下过去
- 梗库互挂：`internet-memes-reference` 流行梗「疯狂星期四」（假通知体变体）＋「穿越回国庆前套餐」

## 综合判断原则

**总则：先认骨架，再认话术，最后才认链接**——话术/模板能无限变异（换名词、换机构名、换金额皮），骨架和落点（要你先付一笔小额去解除一个更大的「麻烦」）是稳定的。linkcheck 只管有链接的那一半，无 URL 的纯文案（模板 5 荐彩、模板 7 假通知）全靠骨架识别。
1. **话术 + 链接双重判断**——随机短域名直连只能提中风险，结合话术（医保/积分/优惠券）才定诈骗
2. **同一伙人特征**：尾号 + 模板复用 + 换短链域名撒网——看到第 2 条同模板短信即可确认团伙
3. **本地/局域网 IP**（127.0.0.1、192.168.x、校园网 portal）报红但正常——自家工具
4. **号码归属地矛盾**（自称本地服务但发信号码外地）是辅助信号，人工判断用
5. **链接过期失效 ≠ 诈骗**——老链接展开失败只是失效，不升级为红

## 处置流程（收到短信三步）

```
收到短信
  → ① 看话术：命中上表任一诈骗模板 → 🔴 直接定性
  → ② 看链接：bin/linkcheck <url> 展开短链看真实目标
       - 跳官方主域 → 🟢 官方营销（是否参与用户决定）
       - 跳陌生域 → 🔴 钓鱼（invest 页/随机落地页）
       - 随机短域名直连 → 🟡 结合话术定级
  → ③ 输出：定性 + 依据（话术/跳转目标/域名特征）
```

## linkcheck 判定逻辑修复清单（可复用）

- 跳转偏离分值 25→40：**单条即红**（钓鱼强信号）
- 随机短域名启发式：注册域判断（倒数第二级）+ ≤6字符**且含数字**（修 github/csdn 误伤 + a.baox46 前缀剥离 bug）
- @ 伪装只检测 host 部分（路径 @ 是正常路由）
- 生态域名豁免 BRAND_SUFFIX_WHITELIST（steamcommunity/steamdb/biligame 等）
- 生态主域补进品牌表（baidu/modian/mihoyo/pizzahut/didi——修 snsyun.baidu.com 误报随机域）
- **品牌白名单=域边界匹配**（等于官方域或在其子域下；修子串 `in` 放行 abchina.com.evil.com 漏报，2026-09-08）
- **数字品牌原串也查**（deleet 1→l/3→e 把 139 变 leg，数字品牌永不命中→ 139.com.evil.com 全绿漏报；2026-09-08）
- **跳转偏离按注册域比较**（近似 eTLD+1，.com.cn 等双后缀取三级；修 c.139.com→m.mcloud.139.com 同生态误报，2026-09-08）
- 官方域校准示例：go.abchina.com（农行短链→wx.abchina.com/webank）、c.139.com（移动云盘→m.mcloud.139.com）
