# 短信钓鱼识别 · 实战模式库

> 2026-08-02 二十连实战（用户分三批发 20 条真实短信逐条判定）沉淀。第一批 10 条、第二批 5 条、第三批 5 条。
> 判定核心：**不要单看一条链接**——短信钓鱼靠「文案模板 + 短链域名 + 落地页特征」三者组合识别。

## 一句话铁律

**「积分/XX分即将失效/清空 + 可换华为手机/珠宝/家电 + 陌生短链」= 诈骗。**

**「XX已入账/报销金已打款/健康保护已入账 + 不验证作废 + 随机短链」= 诈骗。**

模板 D 特征：**无 URL 或裸域名，纯微信号引流**——生肖暗语（潴=猪、汼=牛）、码/傌/鎷=六合彩号码、徾/薇/葳/伽徽/矀=微信、淇=期、佪=回、宜莦=生肖、6何采=六合彩、包种=包中。错别字/谐音规避关键词过滤。公安长期打击（2003 安溪、2022 广西团伙）。识别：**无链接 + 生肖暗语 + 加微信 + 「必中/稳了」= 直接忽略**。

**识别特征（两模板通用）：**
| 特征 | 说明 |
|:-----|:-----|
| 同一尾号反复出现 | 都是 1772（有针对性，也可能是同批数据） |
| 积分数字夸张且临期 | 688800/788662 分，「明日到期/今日到期/即将失效/明日清空」——制造紧迫 |
| 可换高价值实物 | 华为手机/珠宝/手表/家电——正常运营商积分换礼没这么大方 |
| 短链域名每次不同 | buf8.cn / m0u5.cn / x8l.cn / buo0.cn（积分）；1rk.cn / tf1.cn / kq1.cn（医保）——换域名躲封禁 |
| 落地页全是投资诈骗 | 积分类展开全是 `/pages/invest/index?type=1&code=...`（yto086.cn / meibain.cn / ty6j.com / jfoo88.cn） |
| 医保类直连不跳转 | 1rk.cn/tf1.cn/kq1.cn 直接落地（不给看跳转链的机会）——**高级诈骗手法** |
| 「拒收请回复R」 | 伪装正规营销的退订话术，钓鱼也照抄 |

**关键判断：同文案不同域名 = 批量撒网。** 同一个「688800分」模板配 4 个不同短链域 + 4 个不同落地页，就是同一伙人换马甲。发现一条这种短信，搜索同文案其他变体是标准动作。医保/保险同伙同理（19/20 文案几乎逐字相同，只换机构名+短链域）。

### 落地页特征

```
/pages/invest/index?type=1&code=XXX&cate_id=NNN&phone_...
```

所有积分兑换诈骗的落地页都长这样——**uniapp 投资页模板**。看到 `invest` + `code=` 参数 + 陌生域名，不用看文案直接判红。

**真官方 vs 钓鱼的区别：**
- 官方文案带具体上下文（订单号/商品名/AI豆明细），钓鱼全是模糊的大数字
- 官方短链域名固定（dx.10086.cn、cmbt.cn、3.cn），钓鱼每次换新域
- 官方跳转落自家主域，钓鱼落陌生 invest 页
- 官方会写「可登录XX APP 查询」，钓鱼只有「戳/换/兑/领」动词 + 短链
- **官方短链域名不一定常见后缀**：t.hk.uy（.uy 乌拉圭）、3.cn——验证看跳转落点是否官方主域，不看后缀

## 流程

1. **先展开短链看真实目标，不直接点**（`bin/linkcheck <url>` 默认 follow）
2. 判文案模板：积分临期+高价值实物+陌生短链 → 直接红
3. 判落地页：`/pages/invest/index?type=1` → 直接红
4. 同文案搜索变体：发现一条钓鱼 → 搜「688800分」「即将失效 可换」确认是否同伙
5. 真官方 → 说明是哪家、为什么可信；营销类（如 Trae「100%有礼」）提示「官方活动，可参与，别指望大奖」

## 已知坑

- 官方也会用营销话术（Trae「100%有礼，最高100次速通额度」）——**话术夸张 ≠ 钓鱼**，看域名和跳转落点
- 官方短链域名可能缩得很短（cmbt.cn）看起来像仿冒——**先验证再下结论**（知乎/官方通告/跳转落点），验证过才进可信白名单
- 招行官方短链 cmbt.cn 曾被误报仿冒——`TRUSTED_SHORTENER_MAP` 就是为此建的（规则：命中白名单且跳转落官方主域才绿；跳偏仍红）
- 跳转偏离到陌生域是钓鱼强信号——linkcheck 对它单条 +40 直接红，不能只给黄
- **不跳转的随机短域名直连 = 高级诈骗手法**（1rk.cn/tf1.cn/kq1.cn/tianlihui8.cn 案例）：不给看跳转链的机会，脚本只能凭「随机短域名」启发式提中风险——**必须结合话术**：医保/积分/优惠券话术 → 直接当诈骗处理。linkcheck 的 `suspicious-random-domain` 信号（**注册域 ≤6 字符** + 非品牌 + 直连，含数字更可疑——2026-08-02 从 ≤4 放宽到 ≤6 是因为 xsx700.cc 6 字符随机串漏报；用注册域判断而非第一个标签，避免 a.baox46.cn 被剥成空）
- **@ 伪装只检测 host 部分**：`websim.com/@xxx` 路径里的 @ 是正常路由，不是 userinfo——早期误报已修
- **生态站误报**：steamcommunity/steamdb/biligame 等正当生态站含品牌词被误报仿冒——`BRAND_SUFFIX_WHITELIST` 豁免
- **2026-07-30 美团异地盗刷案**：收到「美团优惠券/红包」类短信 + 私人域名（如 a.tianlihui8.cn），结合近期诈骗案定性——假借大平台名的优惠券短信要格外小心
