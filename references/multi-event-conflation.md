# 多事件并置：真事件拼成的假故事

> 适用：转发的“连环”“全线”“一夜之间”式爆料，尤其是「A 暴跌 + B 挤兑 + C 停运，原因你猜」。

## 怎么拆

1. **逐条单查**：把 3–4 个分句拆成独立事件，每条都给一个定性——真 / 部分真 / 无关。
2. **再问共同原因**：把定性排好后再问「它们有因果吗」。多数时候没有，只是同一周。
3. **标出转发者加的那句**：通常只有一句是编的（“挤兑”“停止放款”“全面晚点”），其余都是原报道里的真事。
4. **结论分三层写**：每条真假 → 串联是否成立 → 哪句是转发者自己加的。

## 单位陷阱（市场类必查）

- 指数是**点数**，报道跌的是**百分比**，「蒸发多少亿/兆」是**市值**——三个口径不能互换。
- 看到「暴跌 73 兆」这类量词，先把市值换算回百分比，再对一遍当日报道；对不上就是换错了单位或换了口径。
- 同一事件的媒体报道数字差一档（1800 亿 vs 1900 亿）通常是统计窗口不同，列出两个口径并标清，不要取平均值。

## 一批图里混着真截图、伪快讯、无关素材

同一波转发常常三张一组：盘口/行情截图（真）、微博或门户快讯截图（要验发布主体与时间）、以及一张**根本无关的图**（游戏台词、影视剧截图、老新闻）。

- **一张一张定性**，别用「基本属实」一句糊过去；无关的那张要明确说「这是巧合，不是料」。
- 快讯截图的验法：发布主体是否为该媒体官方号、时间能否对上、正文能否在该媒体站内检索到；只有截图、官网/站内搜不到 → 存疑。
- 反向错误也要防：因为一张图假，就把一组的真截图也当假；或者因为一张真，就整批放行。
- **预测市场／赌盘不是官方**：Polymarket 一类赔率只说明「有人在下注」，不是事实认定，也不是公司口风。同一个百分比在中文转述里可能指不同盘口（免职概率 vs 某某接任概率），引用时写清「赌盘口径」，与「公司声明」「董事会决议」分栏。

## 实战形态（抽象后）

| 转发说法 | 单条定性 | 串联 |
|---|---|---|
| 股市暴跌 + 银行挤兑 + 火车全面晚点 | 股市真（AI 股回调，史上第三大点数跌幅）；银行真但是**系统故障**（ATM/交易中断，非挤兑、非停贷）；火车真但是**局部**（人身事故致几条线路调整） | 无共同原因，同日巧合 |

一句话收口：**「每条都查得到，连在一起查不到」——这就是并置谬误的特征。**
