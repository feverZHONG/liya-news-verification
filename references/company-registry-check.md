# 企业主体核证 · 官网页脚 / ICP 备案 / 运营方实锤

> **2026-09-12 沉淀**（一次「两款产品是不是同一家运营」的主体对照实测）。用途：核「某产品/网站归谁运营」「A 和 B 是不是同一家」这类主张的真伪——争论现场最常见的形态是「一方说同主体无隔离、一方说跨主体物理隔绝」，而两边都可能没查过官方数据。

## 一、优先级（从硬到软）

| 级 | 源 | 能给什么 |
|:--|:--|:--|
| 1 | **官网页脚 ICP 备案号** | 最硬的一手源，`curl` 直取；备案号本身就带行政区域前缀（琼/蜀/沪/粤…） |
| 2 | **官网《隐私政策》/《用户协议》原文** | 明写「由 XX 公司**运营**」的 = 运营方实锤（比备案更直接：备案只证明主体存在，隐私政策才说谁在运营） |
| 3 | **第三方备案查询**（补主体名/审核日期） | 页脚只给备案号，「号 → 公司名」要在这里补 |
| 4 | **工商关联**（百科/企业信息） | 补「谁控股谁」；二手，标注来源 |
| 5 | ⚠️ 争论当事人的说辞（知乎答/评论区） | **只当线索，不当证据** |

## 二、命令

```bash
# ① 官网页脚（一手源，最省时间）
curl -sL --compressed -A 'Mozilla/5.0' https://www.<官网>/ \
  | grep -oE 'ICP备[0-9]+号-[0-9]+|增值电信业务经营许可证[^<]{0,20}|[^<>]{0,25}有限公司'

# ② 隐私政策/用户协议页（找「由……运营」原句）
curl -sL --compressed -A 'Mozilla/5.0' https://www.<官网>/<privacy-path>.html \
  | python3 -c "import sys,re;t=re.sub(r'<(script|style).*?</\\1>','',sys.stdin.read(),flags=re.S);t=re.sub(r'<[^>]+>',' ',t);print(re.sub(r'\s+',' ',t)[:1500])"

# ③ 备案号 → 主体（公共 ID/KEY，频控严，失败 sleep 30~40s 重试）
curl -s 'https://cn.apihz.cn/api/wangzhan/icp.php?id=88888888&key=88888888&domain=<域名>'
# → {"icp":"琼ICP备2021xxxx号-4","unit":"XX公司","time":"2026-01-16","type":"企业"}

# ④ 备案历史镜像（页面类，服务端渲染）
curl -sL 'https://icplishi.com/<域名>/'
```

## 三、坑（都实测过）

- **JS 渲染站点的页脚 curl 取不到**（xoyo.com 系、seasungames.cn 均如此）→ **别在猜域名上耗时间**：从搜索结果反查真实域名再抓页脚。实测剑侠世界4 官网真身 = `js4.seasungames.cn`（`jxsj4.com` / `jxsj4.cn` / `jxsj4.xoyo.com` / `jx4.xoyo.com` 一路猜全空）
- **apihz 公共接口频控极严**（同一分钟连打必 400，要 `sleep 20~40s`），且**不支持 history / 按主体查**（`icphistory.php` 返回 404）
- `jxsj.xoyo.com` 这类站 return 200 但只有 7KB 框架页，grep 不到备案号 ≠ 没备案
- 页脚的备案号 + 版权署名（`Copyright © … XX公司`）通常指向**法人主体**；「谁在运营」还是要看隐私政策原文——两者可能不同层级

## 四、产物写法（避免把中间结论写成结论）

分列记录，不合并：**主体（备案查询所得）/ 备案号 / 审核通过日 / 页脚版权署名 / 隐私政策运营方原句**。

- ✅ 可以下的判断：「A 与 B **是不同法人**」（备案主体名不同）+「二者**同属同一母公司**」（工商佐证）——这是**中间结论**，比争论双方的说法都准确
- ❌ 不许写：「备案主体 = 运营方」（除非隐私政策原文支撑）；也不许把「同一母公司」直接升格成「同一团队无隔离」或反之
- 页脚常附**增值电信业务经营许可证**（如「琼B2-20210572」）与**公网安备**（`46902302000767` 中 `469023` 能反推注册地行政区划）——是交叉验证主体注册地的额外抓手
